# 🔍 Panduan Pencarian Dokter

## Cara Mencari Dokter

### 1. Pencarian Dasar
```
┌─────────────────────────────────────────────┐
│ [🔍 Cari dokter...]           [Cari] [X]   │
└─────────────────────────────────────────────┘
```

**Langkah:**
1. Ketik nama dokter di kotak pencarian
2. Klik tombol "Cari" atau tekan Enter
3. Hasil akan ditampilkan

### 2. Apa yang Bisa Dicari?

✅ **Nama Dokter**
```
Contoh: "Ahmad", "Siti", "Rina"
```

✅ **Nomor STR** (Surat Tanda Registrasi)
```
Contoh: "123456", "223456"
```

✅ **Nomor SIP** (Surat Izin Praktik)
```
Contoh: "503/SIP", "2020/001"
```

✅ **Email Dokter**
```
Contoh: "ahmad.fauzi", "@klinik.com"
```

## 💡 Tips Pencarian

### Tip 1: Gunakan Kata Kunci Pendek
❌ Kurang efektif: "Dokter Ahmad Fauzi yang praktek di klinik"
✅ Lebih baik: "Ahmad"

### Tip 2: Tidak Perlu Lengkap
❌ Tidak perlu: "Dr. Ahmad Fauzi, S.Ked"
✅ Cukup: "Ahmad"

### Tip 3: Case Insensitive
✅ "ahmad" = "Ahmad" = "AHMAD"

### Tip 4: Gunakan Keyboard Shortcut
⌨️ Tekan **Ctrl+K** (Windows) atau **Cmd+K** (Mac) untuk langsung focus ke search box

## 📊 Memahami Hasil Pencarian

### Jika Ada Hasil
```
┌─────────────────────────────────────────────┐
│ ℹ️ Menampilkan 2 hasil untuk "Ahmad"        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 👤 Dr. Ahmad Fauzi                          │
│    Dokter Umum                              │
│    [💬 Chat Sekarang]                       │
└─────────────────────────────────────────────┘
```

**Perhatikan:**
- Kata yang dicari akan di-highlight dengan warna kuning
- Jumlah hasil ditampilkan di banner biru

### Jika Tidak Ada Hasil
```
┌─────────────────────────────────────────────┐
│         👨‍⚕️                                  │
│   Tidak Ada Dokter Ditemukan                │
│   Maaf, tidak ada dokter yang sesuai...     │
│   [← Lihat Semua Dokter]                    │
└─────────────────────────────────────────────┘
```

**Solusi:**
1. Cek ejaan kata kunci
2. Gunakan kata kunci yang lebih pendek
3. Klik "Lihat Semua Dokter" untuk reset

## 🔄 Menghapus Pencarian

### Cara 1: Tombol X
Klik tombol **X merah** di sebelah tombol "Cari"

### Cara 2: Hapus Manual
1. Hapus text di search box
2. Klik "Cari" atau tekan Enter

## ❓ FAQ

### Q: Apakah pencarian case-sensitive?
**A:** Tidak. "ahmad", "Ahmad", dan "AHMAD" akan memberikan hasil yang sama.

### Q: Berapa karakter minimal untuk search?
**A:** Tidak ada minimal. Bahkan 1 karakter bisa di-search.

### Q: Apakah bisa search dengan spasi?
**A:** Ya. Contoh: "Dr Ahmad" akan mencari dokter dengan nama yang mengandung "Dr Ahmad".

### Q: Hasil search tidak muncul?
**A:** Coba:
1. Cek ejaan
2. Gunakan kata kunci lebih pendek
3. Refresh halaman
4. Clear browser cache

### Q: Bagaimana cara melihat semua dokter lagi?
**A:** Klik tombol X merah atau klik "Lihat Semua Dokter" di halaman no results.

### Q: Apakah search tersimpan?
**A:** Tidak. Search tidak tersimpan di history. Setiap kali refresh, search akan reset.
